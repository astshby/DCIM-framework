# Reflect

Reflect0 learns from compiler AND digital-flow generated layouts. Compare hierarchy,
block dimensions, pins, repeated structure and packing; distinguish observations
from hypothesized mechanisms. Derive a bounded next construction, not a generic
learning essay. Bind its learning IDs, module/interface, checks and stop condition.

Read the saved request. Compare available human proposals, AI ideas and measured
algorithm proposals. Human proposals are optional. Run `planner.py` before requesting
Reflect to search new orderings, row splits/merges and allowed orientations. Use
cost/feasibility/diversity evidence to select a discriminating test; proxy ranking
cannot claim routed or electrical superiority. Proposals can also request new
operators for a future framework revision; unsupported operations are not executed.

Return an actual AI reply: request_id/digest, author=ai, short comparison, evidence,
one concise reflection, route proposals/updates, decision build or close and the
next bounded task. `workflow.py ... reflect` validates it. Every reviewed round
requires reflection even when continuing, failing or closing. Keep useful human
feedback and algorithm provenance; do not fabricate absent sources or hidden reasoning.
