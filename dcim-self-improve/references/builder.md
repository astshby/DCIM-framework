# Builder

Consume the current context packet once; use its token for deltas. Confirm task,
learning IDs, selected route, allowed geometry execution, checks and candidate
budget. Use `builder.py --run RUN --candidate ID` to create and execute a new
`draw.py` with its exact inputs and helper versions. Each candidate retains actual
hierarchical geometry and an SVG, execution logs and immutable evidence copies.
Actual instance transforms are read back into placement_state.json and bound to
the selected search/baseline. The drawing is a physical composition study; it does not invent inter-block nets.

For a new route supply a new explicit plan through Reflect; don't silently change
the task. Local implementation failures stay within this bounded task. Preserve
failed programs and results. Submit `workflow.py ... result --input FILE` with
round, task_id, outcome, summary and evidence IDs. When retaining multiple
candidates, set baseline_candidate to the primary output for the next Reflect.
It must belong to this round and be included in result evidence. Propose short action/experience
records for Analyst. Do not write accepted memory or assign the next task.


## Learning target binding and general experience

Task learning_goals identify active, scoped hypotheses and required checks.
The fixed builder writes the exact goal versions to learning_contract.json in
EVERY candidate; retain this alongside draw.py, actual geometry and inputs.
Do not drop a difficult check or substitute an easier goal during local repair.
An unsupported construction remains an explicit capability gap.

- Verify hierarchy transforms and boundary ownership (wells, taps, supplies and
  rails) at assembled scope. Reusing a proven leaf does not qualify its parent.
- Screen the smallest real repeated seam before replicating a primitive. Old
  transistor dimensions, routing layers or spacing tricks are not generic recipes.
- A local route repair can change neighboring conflicts; preserve before/after
  connectivity and inspect the affected neighborhood independently.
- Retain the full parent including periphery, routing and control. Bare-array
  compaction is not evidence of a smaller complete DCIM macro.
- Use disjoint candidate/output namespaces. Preserve failed programs and raw logs,
  including partially generated layouts; summaries do not replace raw evidence.

Method sources: [sources.md](sources.md). Fresh route-specific lessons stay in
structured short memory; do not grow this file into a per-round diary.


Enforce the mandatory PP/NP abutment, real body-supply/TAP and compact-preexperiment constraints in SKILL.md. Retain seam geometry and final assembled validation evidence; do not substitute a violation count for diagnosis.


The program may add role_experience from explicitly configured, pinned experience
bundles. These are reviewed source methods, always reference-only in this run;
inspect source_status, conditions and evidence before a new test. To maintain
reusable experience after review, publish selected current lessons with
experience.py; see experience-memory.md. Static role text remains versioned policy,
not a per-round journal. No automatic write to the installed guide is performed.

For transistor_proxy tasks or campaign stage bindings, read [transistor-planning.md](transistor-planning.md). Preserve the existing role order and explicit physical verification limits.

For two-scale scope selection, native-seam contracts or a private physical Builder, read [two-scale.md](two-scale.md). Analyst includes reviewed experience submission.


## Relative scope construction
Consume the exact scope_decision recorded by Reflect. Execute only the declared
ordered operations through the supported decoder; retain hierarchy_state.json,
scope-transition.json, actual leaf placements and hierarchy-interfaces.json.
Check child-relative transforms and immutable source/endpoint identity before
and after group moves. Inherited MUST checks are task obligations, never a
best-effort memory lookup. Treat physical-only rows/wells/TAPs as explicit
construction owners; connected rails alone do not establish body closure.
