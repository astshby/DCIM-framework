# Task admission

Only a committed Reflect reply assigns a Builder task. It binds a module, stage,
route, goal, learning IDs, explicit checks, max_candidates and stop condition.
Execution must match its representation: geometry_only, transistor_proxy, or an
explicit captured physical_adapter. Physical adapters invoke private recipes;
framework setup and software tests do not authorize EDA. Optional action_guard
binds actual parent inputs, fixed actions and their affected checks before the
recipe runs. It supplies no automatic physical decoder or qualification.
Keep proposed routes with their source (ai/algorithm), mechanism, evidence,
expected benefit, minimal distinguishing test and stopping condition.
