# Task admission

Only a committed Reflect reply assigns a Builder task. It binds a module, stage,
route, goal, learning IDs, explicit checks, max_candidates and stop condition.
This release admits geometry_only execution. Live EDA adapters and permission
binding remain a future extension. Framework checks cannot expand that scope.
Keep proposed routes with their source (human/ai/algorithm), mechanism, evidence,
expected benefit, minimal distinguishing test and stopping condition.
