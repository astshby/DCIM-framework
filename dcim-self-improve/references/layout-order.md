# Learning before construction

Reflect0 measures compiler SRAM and digital-flow logic before specifying a next
construction. Establish functional interfaces and geometry compatibility first.
Learn SRAM, multiplier, adder, selector/control and accumulator as appropriate,
then redesign the macro using the evidence. No four-SRAM grouping, device count,
fixed topology, node or decoder ratio is prescribed. Local nonminimal blocks may
improve total routed macro cost. Geometry search is not functional synthesis.
