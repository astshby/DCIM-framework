# Selected generic improve-3 guidance

These lessons were selected from the read-only improve-3 SKILL and role/context/
experience/layout/admission references during the 2026-11-12 migration. The source
manifest and scoped software results stay in the external migration audit.
They extend task/context guidance within the existing executable API. They add
no runtime schema, new role or implied physical acceptance.

## Bounded work and lifecycle

Assign one connected block or decisive experiment with exact baseline, owner,
parent dimensions/function/interfaces, local freedoms, required checks, resource
scope, outputs and stop boundary. Keep ordinary contact, pin, routing and rule
repairs inside that active Builder task. A structural/interface change returns
for an explicit decision. Use fresh task context for a new substantive assignment
where the native API supports it. Record actual isolation and agent identity.
A delivered agent's transcript is outside default successor context.

Pass the current candidate/code bindings, concise result, applicable constraints,
scoped experience and terminal or explicitly transferred jobs. Inspect actual
state and job ownership before recovering. Preserve failed trials and avoid
repeating submitted work. A run continues using its pinned scripts and rules.

## Evidence reuse and experience

Reuse completed checks only when their exact dependencies and claimed scope
remain unchanged and bound. Missing or conflicting provenance, changed circuit/
sizing or tool readers trigger affected targeted checks. Tool changes receive
appropriate positive/negative regressions. Hashes establish byte identity.
Geometry, DRC, independent source LVS, function, ERC and electrical/parent
qualification retain separate conclusions. A software pass supplies no EDA result.

Keep stage/node-rule-domain/module/route summaries. Analyst selects relevant
mechanisms, marks applicability and records accepted/narrowed/rejected/uncertain
experience or explicit no-new outcome. Deferred or superseded routes keep short
reopening criteria and original evidence links. Avoid importing retired repair
diaries into every task. Cross-node mechanisms remain hypotheses requiring checks.

Analyst's decision includes actual concise reflection, including failed and final
results, and a concrete next task or closure. Reusing a diagnosed mechanism is
valid guidance. Submit transitions through this branch's actual runtime. The
integrated API supports its documented combined decision. Explicit legacy
request/reflect callers retain their original validation contract. This guidance
does not silently alter old state transitions or their required fields.

## Physical rows, seams and complete parents

Bind exact independent circuit and reference top/source identity. Carry inline
architecture intent for parent W/H, functional row origins/heights/phases,
actual order/transforms, straight continuous intended PP/NP bands, TAP/body/
termination ownership and signal/PG access. Numeric grouping, layers, pitch,
model names and exact compiler filenames remain private per-node task inputs.

Require direct PP/NP abutment at intended interfaces without artificial gap or
overlap. Remove redundant TAP/context only with actual legal powered same-body
service and applicable final checks. Inspect final transformed masks, legal
repeat context, functional alignment and parent access. DRC zero, matching bbox
height or one common boundary cannot establish all those conditions. Keep named
unknowns on bounded diagnostic screens and full qualification gaps explicit.

Measure the complete joined routed/PG/context envelope. Separate measured
physical costs, replication projections, possible shared-periphery savings and
unknowns. Hard W/H/function/interface constraints apply before area ranking.
A bounded parent observation may resolve uncertainty before costly expansion.
Ordinary diagnosed repair has no newly added competitor or heuristic-engine gate.

## Actual branch limits

This coarse branch supplies its existing block/parameter search, input/evidence
and physical-action guards. Adapters declare affected/frozen conditions.
Those guards do not infer all effects, prove raw measurement truth or grant
EDA permission. It supplies no automatic transistor-to-foundry physical decoder.
Existing experimental incompleteness remains. Use main for the new small workflow.

At structural decisions improve-3 defaults to two mechanism-distinct cheap
screens from the same frozen baseline and matched boundary, with disjoint outputs
and authorized resources. Record evidence-based single-route or serial exceptions
when inputs/resources do not support independent screens. Ordinary diagnosed
repair stays single-route. This task methodology preserves original programmatic
contracts and adds no paired full-macro/PEX gate.
